# InAmigos-NGO-Website
Responsive NGO Awareness Website built using HTML and CSS during my Web Development Internship at InAmigos Foundation.

## Features

* Responsive design
* About NGO section
* Ongoing projects section
* Gallery with images
* Social impact information
* Call-to-action section
* Contact page

## Technologies Used

* HTML5
* CSS3

## Purpose

The purpose of this website is to spread awareness about the initiatives and projects of InAmigos Foundation and encourage people to contribute towards social welfare.
